### Question 1: The Core Value of Physics Simulators
What is the primary industrial engineering reason for utilizing a simulator like Gazebo before deploying robotics code modules onto real physical hardware stacks?

- [ ] A) It reduces the power consumption of battery parameters inside electronic chips.
- [ ] B) It acts as a code compiler and replaces tools like `colcon build`.
- [ ] C) It permits developers to validate safety protocols, optimize tracking equations, and evaluate sensor pipelines inside a zero-risk virtual physics layer before uploading software to expensive hardware.
- [ ] D) Gazebo automatically writes Python package structures inside the source directory folder cache.

<details>
<summary><b>🔍 Click here for the Answer & Technical Reason</b></summary>

**Correct Answer: C**
* **Technical Reason:** Robotics simulation engines replicate authentic world environments by calculating rigid body kinematics, gravity acceleration equations, and collision envelopes. Virtual tracking prevents catastrophic engineering crashes on disk assets during early development cycles.
</details>

### Question 2: Environmental Global Flag Injection (`TURTLEBOT3_MODEL`)
Why do we inject the variable assignment configuration `export TURTLEBOT3_MODEL=burger` directly inside the system's `~/.bashrc` file during setup?

- [ ] A) It accelerates internet connection domain resolution download pipelines.
- [ ] B) It forces the ROS2 launch engine to automatically know the exact structural definitions, kinematics dimensions, and sensor layout topologies of the target robot chassis configuration during ignition.
- [ ] C) It automatically deletes malicious temporary build configuration cache directories.
- [ ] D) It switches the programming framework compilation type from Python to C++.

<details>
<summary><b>🔍 Click here for the Answer & Technical Reason</b></summary>

**Correct Answer: B**
* **Technical Reason:** Launch scripts rely on system environment variables to isolate package nodes profiles dynamically. Defining the structural keyword string locks the framework into processing calculations matching the small dual-wheel `burger` robotics profile automatically across terminal window sessions.
</details>
